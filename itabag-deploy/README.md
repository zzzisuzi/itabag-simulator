# 痛包模拟器 · Ita-bag Simulator

一款**纯本地运行**的痛包排版模拟器：导入痛包正视图 → 标定比例 → 框选痛层区域 → 导入谷子/装饰品排版 → 导出合成图。

- 纯前端，无服务器，图片数据不出本机
- 支持手机与电脑
- 单文件应用

## 使用

打开 <https://zzzisuzi.github.io/itabag-simulator/> 即可直接使用，无需安装。

## 功能

- 导入痛包正视图（长边不足 2048px 时自动放大）
- 标定比例（画线 + 填厘米）
- 框选痛层（快速选择 / 画笔 / 多边形套索）
- 图层管理（移动 / 旋转 / 复制 / 合并 / 排序）
- 导出合成图（带背景 / 透明背景）
- 项目保存与加载
